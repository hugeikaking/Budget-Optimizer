# V5 第一阶段：Budget_Detail 可视化操作台（测试版）

## 定位

此版本只优化两页工作表的显示和交互提示。**保留已实机验收通过的 V4 计算引擎、ThisWorkbook 事件代码、Edit_Plan 和已输入的预算调整。** 不提供正式导出、标黄导出、撤销或自动优化建议。

代码：[src/BudgetOptimizer_V5_UI.bas](../src/BudgetOptimizer_V5_UI.bas)

## 安装（在 V5_Dev.xlsm 副本上）

1. 保留 `Budget_Optimizer_V4_Stable.xlsm` 不动；只打开备份复制出的 `Budget_Optimizer_V5_Dev.xlsm`。
2. Alt+F11 → File → Import File → **只新增** `BudgetOptimizer_V5_UI.bas`。**不要移除现有 V4 模块，也不要更改 ThisWorkbook 事件**。
3. Debug → Compile VBAProject，通过后 Alt+F8 执行 `SetupBudgetOptimizerV5UI` 一次。不要运行旧版 `SetupBudgetOptimizerV4` 重新初始化。
4. 打开 `Budget_Detail` 查看顶部 H40 汇总区、新的实时金额指标卡、第22行列标题及第23行后的明细表。

## 本阶段做了什么

- 顶部深色标题、蓝色试算指标、黄色可编辑输入框、灰色原值列。
- 四块实时指标：27F TTL Sales Amt、Sales Amt YoY、H40 Sales Amt、与 H40 Sales Amt Target 的差额。直接引用现有预算公式和单元格，不另写计算引擎。
- 第22行起的原值/拟修改值并排对比；第 N 列为 `EDITED / ORIGINAL` 输入状态提示。
- F:I 非空输入突出显示；H:I 仍需 R3 设为 YES 才允许调整。
- 修正文案，明确明细修改会自动触发试算。
- **没有移动坐标**：B3 H40、E3 财年、B6:F9 指标、E6:E9 目标、E11 两页合计、R3 权限、R4/R5 状态、23行起 A:M 编辑区均保持兼容。

## 注意事项

- `EDITED` 表示该预算行存在**非空的修改参数输入**，不保证修改后与源值不同；正式导出将单独逐单元格比较原始值和最终值，只有实际不同才标黄。
- J:M 的原始值是 27F **首月参考值**，不一定代表全部 12 个月。在逐月价格有差异时，不能把它们理解成全年常数。
- V4 的 Trial 仍通过重建工作表执行参数刷新，大数据量时可能有一定计算延迟。
- 本版仅格式化和添加辅助公式，不清空 `Edit_Plan`、不改写 `Budget_Data`、不回写预算原文件。
- V5 如有问题，关闭 Dev 文件后打开未改动的 V4 Stable 文件即可回退。

## 验收

1. 新界面自动展示四块卡片，`Budget_Overview!E6` 与 `Budget_Detail!E11` 仍然相等。
2. B3 换 H40，D6:D9、明细行、E6:E9 目标正常切换。
3. F23 修改 Pcs/Set 后，仍停留在 Budget_Detail，Budget_Trial 自动更新；G23 改 S/P 后 TTL 同步变化。
4. Edit_Plan 中已有的 Pcs/Set、S/P、Share、Comp Ratio 修改仍存在。
5. 第 N 列有输入时显示 EDITED，清空输入则显示 ORIGINAL；但只有后续导出功能会判断真正差异。
6. 没有改动 `Budget_Data` 和 V4 Stable 工作簿。

请先完成以上测试，再开发正式的标黄导出与 Change_Log。


## 追加：27F TTL Sales Amt Target / Gap（V5 界面补丁）

- `Budget_Overview!E9`：**27F TTL Sales Amt Target**，用户手动输入非负金额（黄色）。
- `Budget_Overview!E6`：**当前 27F TTL Sales Amt**，来自已有 V4 动态预算计算，不改变。
- `Budget_Overview!E10`：**27F TTL Sales Amt Gap = E6 - E9**；仅有目标输入时显示。负数代表未达到目标，正数代表超过目标。
- `Budget_Detail!H14:K15`：只读显示全局 27F TTL Sales Amt Target。
- `Budget_Detail!L14:O15`：只读显示全局 27F TTL Sales Amt Gap。
- 这两个全局金额字段**不等于** `Budget_Overview!B6` 的 27F Set QTY 台数目标，也**不等于** `Budget_Detail!E8` 当前 H40 的 Sales Amt Target。三个目标分层保留。
- 再次运行 `SetupBudgetOptimizerV5UI` 不会清空 E9 或已有明细修改。

### 追加验收

1. 导入升级后的最新 `BudgetOptimizer_V5_UI.bas` 并编译，运行 `SetupBudgetOptimizerV5UI`。
2. 在 `Budget_Overview!E9` 输入例如 `1000000`，验证 `E10=E6-1000000`。
3. 查看 `Budget_Detail` 下方两个新指标卡同步显示目标和 Gap。
4. 修改明细 S/P 后，`E6` 自动变化，`E9` 保持原值，`E10` 随之重新计算。确认现有 H40 的 `E8` 目标没有被覆盖。
