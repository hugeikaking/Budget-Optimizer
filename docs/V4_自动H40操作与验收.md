# Budget Optimizer V4 — 自动 H40 操作与验收（当前安装说明）

V4 仍为待公司 Excel 验收的测试版。V3 已验收版本保留在 GitHub 作为回退。公司原始数据只能保存在本地，不应上传公开 GitHub。

## 最新安装：仅 .bas + ThisWorkbook 事件

**不要再导入 C_BudgetV4Events.cls。它是旧方法，已弃用。**

1. 先备份现有工作簿。特别注意 Excel 标题栏如果显示 `.xlsx`，请先另存为 `Excel Macro-Enabled Workbook (*.xlsm)`。
2. 打开 VBA 编辑器 `Alt+F11`。在左侧 Modules 下移除 `C_BudgetV4Events`（这是误当普通模块导入的类文件），同时移除旧 `BudgetOptimizer_V4`。保留其他项目 VBA 代码。
3. 导入最新 [BudgetOptimizer_V4.bas](../src/BudgetOptimizer_V4.bas)。
4. 打开 `Microsoft Excel Objects → ThisWorkbook`，将 [ThisWorkbook_V4_event.txt](../src/ThisWorkbook_V4_event.txt) 的 `Workbook_SheetChange` 事件过程粘贴进去。**不要把 .txt 导入为新模块。** 如果已有 `Option Explicit` 不要重复；已有 `Workbook_SheetChange` 须合并事件逻辑，不能复制第二个同名过程。
5. 在 VBA 编辑器依次点击 `Debug → Compile VBAProject`，确认无错误。返回 Excel 运行一次 `SetupBudgetOptimizerV4`。
6. 保存为 `.xlsm`，关闭后再重新打开测试事件是否仍生效。

## 使用

- 第一页 `Budget_Overview`：手动输入一个 26F TTL Set QTY（B5）；27F TTL 年度目标（B6）及机种目标（第40行起 B列）；生成机种 12 个月 Set QTY 建议。每月修改 E:P 后，图表、试算额、YoY 实时跟随。后台按原预算 B 列编号关联，同机种各 H40 同月 Set QTY 一致；显示名来自 M 列 Model。
- 第二页 `Budget_Detail`：在 B3 切换 H40，自动加载第 23 行起各 H40 明细；D/E 设置起止月；F 填 Pcs/Set（非负整数）；G 填 S/P（最多五位小数）；H/I 填 Share/Comp Ratio（需在 R3 解锁，0–100整数）。
- E6:E9 为该 H40 的手动目标，换 H40 自动保存、恢复；D6:D9 为当前 27F 四项试算指标。
- 修改第二页参数后，事件调用静默刷新，后台重新生成 `Budget_Trial` 并叠加第一页已填写的 Set QTY；`Budget_Overview!E6` 与 `Budget_Detail!E11` 应相同。
- 如果 H40 明细很多，自动刷新仍可能需要明显时间；V4 尚非局部增量重算引擎。

## V4 验收顺序

1. `.xlsm` + 编译成功；Setup 完成。
2. B3 切换 H40 自动更换第23行起行列表，四项指标和四项目标对应切换，不再手动运行刷新。
3. 修改 F23 Pcs/Set 后，`Budget_Trial` 试算单元格与金额自动变化，`Budget_Data` 不变。
4. 修改 G23 S/P 后，仅金额变、数量不变。
5. 非法小数、解锁权限、月份范围均正确报错。
6. 第一页 Set QTY 与第二页 S/P 的调整叠加；`Budget_Overview!E6` 与 `Budget_Detail!E11` 相等。
7. 保存、关闭、重新打开 `.xlsm` 后自动事件仍有效。

**本版尚未实现**最终标黄副本导出、正式回写与审批、跨月窗口历史迁移，以及独立的撤销功能。
