# V4 安装修正：不再需要 .cls 文件（2026-11-23）

旧版安装说明中的 `C_BudgetV4Events.cls` **已弃用**。用户截图显示将类文件作为普通模块导入，导致 `VERSION 1.0 CLASS` 被解析为 VBA 代码并报 `Expected: end of statement`。最新 V4 已移除对此类模块的依赖。

**正确安装（优先使用此段）：**

1. 检查标题栏是否以 `.xlsx` 结尾：如果是，先 **File → Save As → Excel Macro-Enabled Workbook (*.xlsm)**，在副本中操作；`.xlsx` 不能正常持久保存宏。
2. Alt+F11，在左侧 Modules 下右键移除误导入的 `C_BudgetV4Events`，以及旧 `BudgetOptimizer_V4` 模块。对自己改过的代码先备份。
3. 从 GitHub 下载并导入最新 [BudgetOptimizer_V4.bas](../src/BudgetOptimizer_V4.bas)（**只导入这个 .bas**）。
4. 打开左侧 `Microsoft Excel Objects → ThisWorkbook`，把 [ThisWorkbook_V4_event.txt](../src/ThisWorkbook_V4_event.txt) 的代码复制粘贴到 `ThisWorkbook` 代码窗口。**不要导入这个 .txt 为模块**。如果 ThisWorkbook 已有代码，不要覆盖既有内容；只添加 Workbook_SheetChange 过程，已有同名过程需合并。
5. VBA 菜单 `Debug → Compile VBAProject`，通过后运行一次 `SetupBudgetOptimizerV4`。
6. 在 Budget_Detail 的 B3 切换 H40，以及 F23/G23 修改数值，验证自动填充与联动。无需运行 StartBudgetV4Events；该宏已从最新版移除。

# Budget Optimizer V4 — 自动 H40 交互版（测试发布）

**V4 基于已验收 V3 计算，仍待公司 Excel 实机验收。上述安装修正优先于以下历史版本说明。**

## 需要下载两个文件（缺一不可）

1. [src/BudgetOptimizer_V4.bas](../src/BudgetOptimizer_V4.bas) — 完整预算逻辑与 H40 自动编辑器。
2. [src/C_BudgetV4Events.cls](../src/C_BudgetV4Events.cls) — Excel 工作表变更事件监听器（实现免手动运行刷新宏）。

**不能只导入 .bas**；类模块 .cls 必须一起导入，否则无法编译 V4。不要修改公司的真实数据文件。公开 GitHub 仓库不可上传真实预算、客户价格或任何敏感资料。

## 从 V3 升级

1. 在公司电脑先复制备份本地 `Budget_Optimizer.xlsm`。在备份副本上升级。原有 `Budget_Overview` 的 B5/B6、机种目标、E:P 月度计划和 `Base26` 数据保留。
2. Excel → Alt+F11，展开该 .xlsm 项目的 `Modules`，**移除旧 `BudgetOptimizer_V3` 模块**。移除旧模块前，如有个人修改可先导出备份。不要让 V3/V4 的同名公共过程并存。
3. VBA 编辑器 → File → Import File，导入 `C_BudgetV4Events.cls` 和 `BudgetOptimizer_V4.bas`（两个文件）。
4. 在 VBA 编辑器中菜单 Debug → **Compile VBAProject**。如有报错先停止，不要在正式预算上运行。
5. Excel → Developer → Macros，执行一次 **`SetupBudgetOptimizerV4`**。
6. 打开 `Budget_Detail`，应看到第 22 行新增编辑器表头，以及第 23 行起的 H40 明细；`Budget_Overview` 保持原有机种计划。
7. 如果重新打开 .xlsm 后事件监听没有生效，可手动运行一次 **`StartBudgetV4Events`**。正常情况下，Excel 打开本工具时会由 `Auto_Open` 自动启动监听。

## 第二页 Budget_Detail（自动互动）

- **B3**：H40 下拉列表，选择后会自动加载所选 H40 的原预算行信息，不必手动刷新。
- **D:E（第 23 行起）**：修改生效的起止月份，例如 `2027_4` 至 `2028_3`，默认 27F 全年。
- **F**：New Pcs/Set，非负整数。
- **G**：New S/P，非负，最多 5 位小数。
- **H**：New Share（0–100 整数，需 `R3=YES` 解锁）。
- **I**：New Comp Ratio（0–100 整数，需 `R3=YES` 解锁）。
- **J:M**：原始预算行在 27F 第一个月的对应参数参考值（只读参考，不代表 12 个月每月相同）。
- **E6:E9**：本 H40 的四项目标输入；切换 H40 时会从辅助表 `H40_Targets` 自动保存/恢复。
- **D6:D9**：根据当前选择的 H40，使用 `SUMIF` 自动显示 27F 四项试算指标；B/C 列是 26F 全年基准和窗口数据。F6:F9 显示目标差异。
- **R3**：Share/Comp Ratio 锁定开关，默认 NO。**只影响新的编辑输入，不撤销旧试算计划**。
- **R4**：运行状态；**R5**：当前 H40 显示的预算行数。

F:I 有修改时，会更新后台 `Edit_Plan`，随后调用静默的 `RefreshBudgetSheet1Preview True`。不需要手动运行宏；也不会弹出每次刷新完成的消息。**自动刷新仍重建整个 Budget_Trial，数据量很大时可能存在明显等待；V4 的重点是自动操作而不是局部增量计算引擎。**

### 两页联动

- 仍从原始 `Sheet1 / Budget_Data` 新建 `Budget_Trial`；
- 优先应用后台 `Edit_Plan` 参数调整；
- 再重新应用 `Budget_Overview` 的机种月度 Set QTY 计划；
- 金额、Demand/Sales 指标、TTL Sales Amt、YoY 用 Excel 公式重算；
- **只在试算副本中发生数值变更，不直接回写原始预算**。

## 27F 财年与格式

- FY 27F = 2027/04–2028/03。
- 26F TTL Set QTY 只在 `Budget_Overview!B5` 手动填写一个年度总台数，不从原始明细自动计算。
- Set QTY、Demand Qty/Amt、Sales Qty/Amt 显示千分位且无小数（显示精度不影响底层实际值）；S/P 最多五位小数；YoY 显示百分比。
- 27F 机种月度曲线默认 4–9 月升、10 月降、11–1 月升、2 月降、3 月升，取两位有效数字的整数。
- 机种识别使用原始预算 B 列内部键；界面可见 Model 来自 M 列。

## 公司 Excel 验收清单

1. 备份 V3 xlsm，确认 V4 只导入一套公共模块和一个事件类。
2. Setup 后选择 B3 不同 H40，第 23 行起预算行、D6:D9、B6:C9、E6:E9 目标必须跟着变化，不能沿用上一个 H40 的输入。
3. 在 F23 修改 Pcs/Set（整数），不手动运行宏，检查 `Budget_Trial` Pcs/Set 和金额是否自动更新，原始 Budget_Data 不变。
4. 清空 F23 后恢复原值；在 G23 输入合法 S/P 后，Demand Amt 和 Sales Amt 变化，Demand Qty 和 Sales Qty 不变。
5. 输入六位小数 S/P、带小数的 Pcs/Set、未解锁的 Share/Comp Ratio 应弹出错误（暂不自动撤销用户输入，需自行改正后再测试）。
6. 修改第一页机种的任一月份 Set QTY，再在第二页修改 S/P，检查台数未复原，且 Overview E6 与 Detail E11 保持相等。
7. 第二页 E6:E9 目标：切换 H40 后重新返回，原 H40 的目标应恢复。
8. 关闭并重新打开测试 xlsm，检查无须每次手动启动事件（若失败可运行 StartBudgetV4Events）。
9. 对照原表选中 H40 的 27F 4 项指标，确保计算口径仍然正确。

**当前仍未实现**：输入后只刷新受影响的部分行（性能优化）、Undo/回退、正式预算回写、标黄导出、最终审批、跨滚动文件迁移。自动试算不可当作正式修改确认。
