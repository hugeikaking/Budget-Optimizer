# V5 增强：H40 四项目标批量粘贴 + Detail G6:G9 完成率

## 目的

不用逐个切换 H40 输入 `Budget_Detail!E6:E9`。集中粘贴各个 H40 的四项年度目标，按一次导入后，V4 原有的 H40 切换功能会自动带出对应目标。同时在 `Budget_Detail!G6:G9` 显示 `D/E`，整数百分比，无小数。

**状态**：GitHub 代码已提供；尚待公司 Excel 实机测试。此次是独立增强模块，不修改已验收的 V4、V5 简化导出和导出按钮。

## 1. 先备份

1. 保存当前已修改预算的 `.xlsm`。
2. 用“另存为”做一份测试副本，例如 `Budget_Optimizer_V5_Dev.xlsm`。
3. 本次不运行 `SetupBudgetOptimizerV4`，不运行季节性台数重分配，不重新导入原预算。

## 2. 安装与准备

1. 从 [BudgetOptimizer_V5_TargetImport.bas](../src/BudgetOptimizer_V5_TargetImport.bas) 下载 **Raw** 文件。
2. 在 VBA 编辑器按 Alt+F11 → File → Import File 导入新模块；不删除任何已有模块、不替换 ThisWorkbook。
3. 运行 Debug → Compile VBAProject。
4. Alt+F8 → 运行 `SetupBudgetV5TargetsImport` 一次。
5. Excel 新增工作表 `H40_Target_Import`；`Budget_Detail!G5` 为 **Current / Target**，G6:G9 显示整数百分比。

## 3. 批量粘贴结构

从 `H40_Target_Import!A2` 开始粘贴。A 列为 H40 编码，**B:E 的顺序必须与 Budget_Detail E6:E9 一致**：

| A：H40 | B：Demand Amt Target | C：Demand Qty Target | D：Sales Amt Target | E：Sales Qty Target |
|---|---:|---:|---:|---:|
| 12345 | 100000 | 25000 | 90000 | 22500 |
| 123456 | 200000 | 40000 | 150000 | 30000 |

上述数字仅为演示。尽量将 H40 编码列格式设为文本；模块已预设 A 列为文本。五位 H40 尾随空格会自动去除后匹配；不会改动预算原始 S 列。

- **空白目标**：保留该 H40 已保存的原目标。
- **0**：合法目标值，代表明确将目标设为零；G 列因分母为零会显示空白。
- **其他未列出的 H40**：保留已有四项目标，不受影响。
- 重复 H40、找不到的 H40、非数字、负数、缺少 H40 的数据行，会停止导入并报告错误。
- 当前 H40 如在导入清单内，会立即刷新 E6:E9，避免下次切换时被屏幕上旧目标覆盖。

## 4. 一次导入

Alt+F8 → `ImportBudgetV5Targets` → 检查提示中的 H40 数量 → Yes。然后在 `Budget_Detail!B3` 切换不同 H40，核对 E6:E9 目标。

## 5. G6:G9 计算规则

| 行 | D 列当前值 | E 列目标值 | G 列显示 |
|---|---|---|---|
| 6 | Demand Amt | Demand Amt Target | `D6/E6` |
| 7 | Demand Qty | Demand Qty Target | `D7/E7` |
| 8 | Sales Amt | Sales Amt Target | `D8/E8` |
| 9 | Sales Qty | Sales Qty Target | `D9/E9` |

数字显示为 `0%`（例如 97.6% 显示 98%）；实际计算精度不被修改。目标为空或 0 时显示空白，避免除以零。G 列是公式，不需要手动输入；随 D 列实时计算及 H40 切换自动更新。

## 6. 验收顺序

1. 选一个已有手工输入 E6:E9 的 H40，记下旧目标。
2. 在导入表中先只粘贴 **两个 H40** 测试（一个五位带尾随空格、一个六位）。
3. 导入后在 B3 切换两者，确认 E6:E9 正确且每个 H40 相互独立。
4. G6:G9 对应 D/E 且百分比不显示小数。
5. 检查未导入的 H40 原目标未丢失；之前已修改的 Detail F:I、Overview E:P 和 Trial 结果没有变化。
6. 试试错误数据：例如重复 H40，导入应阻止写入。确认后恢复正确清单。
7. 真正批量导入前清理测试数据，或整表覆盖 `H40_Target_Import` 中旧数据，避免残留的 H40 被重复导入。

**特别注意**：导入代码不会先清空粘贴表，便于保留和复核。粘贴下一批前应主动清除 A2:E 的旧行；只清除导入表，不清除 `H40_Targets`。

## 7. 安全边界

- 只更新 `H40_Targets` 的 B:E 目标列（以及新 H40 的 A 列键），不修改 `Budget_Data`、`Edit_Plan` 或 `Budget_Trial`。
- `Budget_Detail!E6:E9` 保持人工可修改，切换 B3 时继续由现有 V4 读写。
- 现有 `BudgetOptimizer_V4`、`BudgetOptimizer_V5_UI`、`BudgetOptimizer_V5_ExportSimple` 和导出按钮模块保持原样。
- 不把客户真实预算数据、目标表上传到公开 GitHub。
