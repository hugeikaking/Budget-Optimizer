# V5 简化版导出：复制回公司正式模板

**状态：测试版，未在公司 Excel 实机验证。** 不改 V4/V5 已经通过的试算和界面。旧的 `ExportBudgetV5YellowCopy` 保留，但这次请使用新的 `ExportBudgetV5SimpleCopy`。

代码：[src/BudgetOptimizer_V5_ExportSimple.bas](../src/BudgetOptimizer_V5_ExportSimple.bas)

## 输出规则

- 输出一个独立 `.xlsx`，只有原预算 `Sheet1`，保留原工作表的行列位置、列宽、行高及主要单元格样式。
- 所有单元格公式转换为**原预算计算结果的值**，外部定义名称在**新副本**中删除。
- X:DS 内的 5 组 20 个月输入值，逐格与 `Budget_Trial` 比较，只写入实际差异值，并把相应单元格填充黄色。
- A 列：存在任意真实差异的行写入字面量 `C`；不导出动态 C 公式。未修改行保留原来 A 列内容。
- 不再输出 Change_Log，不要求保留 Sales Amt 公式。**DW:EP Sales Amt 写入 Budget_Trial 当前计算后的数值（静态值，不标黄）**；黄色专用于实际调整过的输入单元格。
- 宏从原始 `Budget_Data` 复制外观，且不修改工具里的 Budget_Data、Budget_Trial。
- 输出副本如果还有真实外部链接（如图表、对象、连接）或残余公式，程序会停止，不报告成功。

## 安装

1. 先备份 `Budget_Optimizer_V5_Dev.xlsm`，保留 V4 Stable。
2. VBA 编辑器导入 `BudgetOptimizer_V5_ExportSimple.bas`，**不要替换 V4、V5_UI、ThisWorkbook，也不用删旧 Export 模块**。
3. Debug → Compile VBAProject，编译无错误后回到 Excel。
4. Alt+F8 → **`ExportBudgetV5SimpleCopy`**，确认并选择一个新的 .xlsx 文件名。
5. 打开新文件核查 Sheet1。务必先用测试数据，在正式粘贴前对比差异。

## 验收要点

1. `Budget_Trial!A10=C` 的示例行，导出 `Sheet1!A10` 应固定为 `C`。
2. 修改过的 12 个月 Pcs/Set 数值应逐月标黄，原值一致的单元格不应被新标黄。
3. 原始文件布局及 B:EP 各列位置不变。
4. 点击某个原来有公式的单元格，公式栏应显示数值而不是公式。导出的 DW:EP 应为 Trial 最新静态金额，与 Trial 相应单元格核对。
5. 将新文件的变更输入值粘贴回公司正式模板后，**检查模板公式有没有重新计算且结果与 Trial 对得上**。
6. 不上传任何公司实际预算数据到公开 GitHub。
