# V5 导出按钮（可选增强）

已通过公司 Excel 验收的 `ExportBudgetV5SimpleCopy` 不作修改。本功能新增操作入口，供测试副本使用。

## 安装

1. 保留 `Budget_Optimizer_V5_Stable.xlsm` 不动，在 `V5_Dev.xlsm` 测试。
2. VBA 编辑器 Alt+F11 → File → Import File，新增 [BudgetOptimizer_V5_ExportButton.bas](../src/BudgetOptimizer_V5_ExportButton.bas)。
3. 保留原有 `BudgetOptimizer_V4`、`BudgetOptimizer_V5_UI`、`BudgetOptimizer_V5_ExportSimple` 和 `ThisWorkbook` 事件。
4. Debug → Compile VBAProject；无报错后 Alt+F8 运行 `SetupBudgetV5ExportButton` **一次**。
5. 打开 `Budget_Overview`，在 H5:K7 位置找到 **EXPORT BUDGET** 按钮（Excel 形状）；单击后会先显示当前修改行数和修改单元格数。
6. 确认后转到现有 `ExportBudgetV5SimpleCopy` 流程：再次确认、选择新的 .xlsx 文件名，生成 Sheet1 数据副本、差异黄色、A 列 C 标识、静态 Sales Amt。

## 规则与保护

- 修改统计与导出使用相同的五组输入列、20 个月以及数值比较容差，统计的是**实际差异**而不是填写过多少调整参数。
- 只新增工作表图形按钮，不插入或删除任何工作表行列、不移动表格、不改变预算计算、原始数据、目标或历史调整。
- 重新执行 Setup 会先删除同名按钮然后重建，不会重复叠加按钮。
- 按钮运行基于当前存储的 `Budget_Trial`；导出前仍应确认明细试算已更新。
- 实际修改行数统计需要扫描数据行与五组 20 个月输入。大表可能需要一段计算时间。
- 此按钮模块尚未在用户公司 Excel 环境实际验收。

## 快速验收

1. 点击按钮，弹窗中显示修改行数、单元格数；与导出文件实际标黄数量核对。
2. 点击 No：不应产生新文件。
3. 点击 Yes 并完成导出：结果与原来手动执行 `ExportBudgetV5SimpleCopy` 一致。
4. 检查已通过验收的 V4 自动试算与 V5_UI 两页展示没有改变。
