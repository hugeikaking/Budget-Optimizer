# M1/M2 模拟工作簿安装与测试

Budget Optimizer M1/M2 测试版使用说明
================================

提供两个文件：
1. Budget_Optimizer_M1M2_Demo.xlsx：脱离公司原始表的模拟预算工作簿
2. BudgetOptimizer_M1M2.bas：需要导入 Excel VBA 的宏源文件

安装（公司 Excel 已允许 VBA）：
1. 打开 Demo.xlsx，先另存为 Excel 启用宏的工作簿（*.xlsm）。
2. Alt + F11 打开 VBA 编辑器。
3. 文件(File) > 导入文件(Import File) > 选择 BudgetOptimizer_M1M2.bas。
4. 关闭 VBA 编辑器，在 Excel 按 Alt + F8，运行 RefreshBudgetPreview。
5. 必须只在模拟文件上测试，暂不应用于公司正式预算表。

单页面操作：
- Budget_Panel!B3：选择 H40-MLCC、H40-RF 或 H40-MIX（手工输入）。
- Budget_Panel!E3：年度，默认 2027。
- Budget_Panel!E6:E9：目标 Demand Amt / Demand Qty / Sales Amt / Sales Qty（可留空）。
- Base26!B:E：第一次输入完整26F全年四项基准，存储在工作簿内。Base26!F 是全年Share录入位。
- Edit_Plan：通过 A 列 Y/N 决定是否应用候选修改，B 列原表行号，C-D 列起止月份，E/F 为 Pcs/Set/S/P，G/H 为高级解锁 Share/Comp Ratio。I列可选验证H40。
- 示例：Edit_Plan!A2 写 Y，E2 写 3，再运行 RefreshBudgetPreview。

计算结果：
- Budget_Panel!B6:B9 = 26F全年基准 + 本次26F表内候选修改差额。
- Budget_Panel!C6:C9 = 26F表内月份的候选汇总。
- Budget_Panel!D6:D9 = 所选年度的表内月份候选汇总。
- Budget_Panel!F6:F9 = 所选年度的候选结果 - 目标。
- B13 = Sales Amt同比；需要在Base26填全年数据才有意义。
- E11 = 该年度全表Sales Amt。
- Budget_Trial = Excel 复制数据页并应用候选数字的试算页；宏会在每次预览时重新生成。

边界/未完成：
- 这不是正式公司文件适配版本；第二张模拟表的S列原本不是H40，因此Demo建立了虚构分类。
- 预算文件固定月份区块与列宽来自示例；月份通过第7行表头解析，不是写死某年的列号。
- Demand Amt和Sales Qty / Demand Qty按模拟表公式计算；正式表公式尚未核对。
- 26F的月度滚动跨文件快照迁移、H40动态下拉、正式原表确认回写与导出修改标黄、自动优化均未实现。
- 如果不能运行VBA，请记录具体错误提示；公司环境可能有不同的权限/保护设置。
- 原始上传文件不会被此工作簿或宏修改。

注意：本公开仓库不存放真实公司数据。模拟工作簿请使用经过确认的合成测试文件，勿从公司设备上传真实预算表。
