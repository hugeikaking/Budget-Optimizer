# V5｜26F TTL Sales Amt + Set QTY 单独输入 Sheet

适用：现有 Budget Optimizer V5 工具。用户的四张 2027F H40 目标表仍按原 `BudgetOptimizer_V5_Target4Sheets.bas` 导入。本增强增加**第五张输入表**，不要求用户每期重新导入 VBA。

## 位置

新增工具工作表 `Budget_26F_Input`：

| 单元格 | 填什么 | 导入到 |
|---|---|---|
| B2 | **26F TTL Sales Amt**，年度总销售金额 | `Budget_Overview!E5` |
| B3 | **26F TTL Set QTY**，年度总台数（整数） | `Budget_Overview!B5` |

两个数字都是**整体 TTL**，不是单独 H40。不要填入 2027F 目标，且不要把 Amount 当成 Demand Amt：这里指 **Sales Amt**。

## 安装步骤（首次一次）

1. 先备份已编辑一半的工具 `.xlsm`；在开发副本试用。
2. Alt+F11 → File → Import File → 导入 [BudgetOptimizer_V5_26FInput.bas](../src/BudgetOptimizer_V5_26FInput.bas)。
3. Debug → Compile VBAProject；Alt+F8 运行 `SetupBudgetV5_26FInput` 一次。
4. 在 `Budget_26F_Input!B2:B3` 填入 26F TTL Sales Amt 和 Set QTY。
5. Alt+F8 运行 `ImportBudgetV5_26FTotals`，确认导入。此时将 `Budget_Overview!E5/B5` 变为链接到输入表的公式。
6. 可把 `Budget_26F_Input` 拖动到 `H40_Target_Source` 旁边，便于查找；不会影响公式。

**重要：V4 兼容性**——如果使用旧版 `BudgetOptimizer_V4.bas`，每次 `RefreshBudgetSheet1Preview` 重建 Overview 公式时，可能把 `Budget_Overview!E5` 恢复为 `Base26` 合计。GitHub 最新 V4 已加入检查：若 `Budget_26F_Input!B2` 有数字，E5 优先引用这一数字，否则继续用 Base26 汇总。更新 V4 需按备份→删除旧同名模块→导入新版→编译的流程；但**当前已经生效的 26F 数字和预算修改不会因新增第五张输入 Sheet 被清除**。

未更新 V4 时的临时办法：每次刷新 Trial 后再次运行 `ImportBudgetV5_26FTotals`；长期还是推荐更新 V4 使 E5 永久联动。

## 以后每期使用

- 固定使用配置好的 `.xlsm`，不重新导入 VBA。
- 从公司下载最新预算后，先备份并按前述行号/H40 检查更新 Budget_Data；再导入四张 H40 2027F 目标。
- `Budget_26F_Input` 的 B2/B3 直接改为当期 26F 全年数字；**首次链接成功后，Overview 自动同步，无需重复导入**。
- 保持 `Budget_Overview!B6` 的 27F TTL Set QTY **目标**与 B5 的 26F 实际基准分开，`Budget_Overview!E9` 是 27F TTL Sales Amt 目标、E5 是 26F 基准。

## 验收

1. `Budget_26F_Input!B2` 填 26F Amt，`B3` 填 26F Set QTY，运行导入后检查 `Budget_Overview!E5` 和 `B5`。
2. 变更输入表两个数字，Overview 自动更新，`B8`（台数 YoY）和 `E7`（金额 YoY）随之更新。
3. 运行一次 `RefreshBudgetSheet1Preview False` 后检查 E5/B5 未恢复成旧值（需要最新 V4）。
4. 检查 `Budget_Detail` 既有 E6:E9 H40 目标、F:I 调整，`Budget_Trial` 和导出仍正常。
