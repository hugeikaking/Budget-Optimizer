# 预算优化 · Budget Optimizer

用于公司内部 Excel 预算工作簿的 VBA 试算工具（M1/M2 **实验原型**）。

> **公开仓库仅存放通用工具代码和脱敏示例说明；不要提交公司真实预算、客户资料、价格、原始工作簿或运行结果。**

## 目标
- 使用 **S 列**识别 H40 分组；B:W 为固定业务信息，A 列留作 D/A/C 操作标记。
- Set QTY 始终锁定。优先试改 Pcs/Set（非负整数）与 S/P（最多五位小数）；Share、Comp Ratio 仅在明确允许时调整。
- 自动识别横向 20 个月的滚动年月，区分 26F 表内、26F 全年手填基准和 27F。
- 展示 H40 的 Demand Amt、Demand Qty、Sales Amt、Sales Qty 以及同比；在临时副本中试算，不直接修改正式预算工作簿。

## 当前状态
- M1/M2 为**待公司 Excel 环境验证**的原型，尚未实现完整的实时交互、自动优化、正式回写、标黄副本与跨文件滚动历史同步。
- 原型 VBA 模块应当导入一份**脱敏模拟工作簿**另存后的 .xlsm；切勿直接在正式预算上运行。
- 官方结构尚需核对四项指标原始公式与 H40 汇总方式。当前模拟公式不能直接视为公司正式公式。
- 26F 为完整年度手工基准；本期表内 26F 修改仅按照相对当前基准试算的差额反映。滚动文件版本间的快照迁移尚未完成。
